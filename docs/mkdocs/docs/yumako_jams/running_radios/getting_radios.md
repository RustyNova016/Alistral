# Getting radios

By default, alistral doesn't come with any radios. But you can download some from the [official repository](https://codeberg.org/RustyNova016/yumako_jam_radios)

You need to add them to the yumako_jams config folder:

- Linux: `/home/alice/.config/yumako_jams`
  
- Windows: `C:\Users\Alice\AppData\Roaming\yumako_jams`
  
- MacOS: `/Users/Alice/Library/Application Support/yumako_jams`
