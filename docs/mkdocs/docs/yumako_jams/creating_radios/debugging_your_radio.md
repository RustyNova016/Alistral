# Debugging your radio

When making complex radios, it can be easy to start losing track of all the stats, how the score changes, etc... But luckily, there's a way to see exactly how the radio has been generated by going into the logs of Alistral (In the configuration fooder, under logs).

Each log tries to display:
- the layer's id
- The recording MBID
- What it did to it
- Why it did it

To see how a specific track flow through the radio, you can search for its MBID

## A note on limiters

If a radio item is stopped by a limiter, it won't show up as being removed in the logs. This is because the limiter is lazy and won't try to process radio items it knows won't be in the radio.

This doesn't apply to filters, nor any other module. If a module did a thing, and it didn't put a log, please create a bug report
