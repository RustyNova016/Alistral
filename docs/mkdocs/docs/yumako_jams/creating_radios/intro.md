# Getting started (Making radios)

So you have an interest in making radios? That's the section for you. However there's a few requirements:
- Make sure you are familiar with running radios first. It would be dumb to have a radio but not able to use it
- You need some familiarity with the json configuration language. That's how the radios are declared. 
  - yumako_jams also accepts [`json5`](https://json5.org/), but all the documentation will be in json
